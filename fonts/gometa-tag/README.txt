GoMeta Tag — the face of the small "α status" tag beside the GoMeta wordmark on the front page.

GoMetaTag-Bold.woff2 is a Modified Version of JuliaMono Bold (JuliaMono-Bold.woff2, 1,041,344 bytes, fetched on
2026-10-20 from https://cdn.jsdelivr.net/gh/cormullion/juliamono/webfonts/JuliaMono-Bold.woff2):
  - subset to the code points U+0020–007E, U+00A0–00FF, U+0370–03FF, U+2013–2014, U+2018–201D and U+2026
    (basic Latin, Latin-1, Greek and Coptic, the dashes, the curly quotes, the ellipsis);
  - renamed "GoMeta Tag" (family and full name; PostScript name GoMetaTag-Bold), because JuliaMono is released
    under the SIL Open Font License 1.1 with the Reserved Font Name "JuliaMono", and the licence does not allow a
    Modified Version to carry that name;
  - the copyright notice, the licence records and the designer's URLs inside the font are kept as released; the
    derivation is noted in the font's description record.
